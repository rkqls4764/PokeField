# PokéField 제출 증빙 — 2026-10-23

원본 「AI 코어 프로젝트 2회차 요구사항 정의서」 **4장(4.1~4.8)** 에 맞춰 현재 코드와 기존 실제 검증 기록을 정리했다. 이번 작업은 증빙/문서/소스 복사와 무료 UI 재캡처만 수행하며 제품 코드·설정·데이터를 변경하지 않았다.

## 판정 요약

필수 기능12/12는 수정 후 기록 범위 판정이다. 실제 비교 출력의 모순된 문구는 남은 품질 문제다. 최신155개 회귀는 NF 보완 전147개보다 최신이다. 실제 GMS gpt-6.1-sol은 이전 최종 서비스 테스트4회(14,665토큰)이며 이 증빙 정리에서 추가 유료 호출0회다.

현재 UI 캡처는 제품 JS/CSS와 격리 데이터 상태를 쓰고 생성에는 FakeLLM을 사용했다. 실제 GMS JSON 결과와 UI 가짜 생성 화면을 같은 검증으로 합산하지 않는다. 실제 새 위키 HTTP는 운영 연락처가 없어 미실행이며 기존 API 응답 재생/캐시·모의 테스트만 있다.

## 주의

이 ZIP은 **증빙·문서·소스 검토용**이며 대용량 가공 데이터·이미지·운영 Vector DB를 포함한 독립 실행 배포본은 아니다. 데이터 전달 범위는 누락 점검표를 따른다. 원본 PDF는 제공 자료의 대외비 표기를 유지하며 공개 배포하지 않는다. 이미지가 포함된 캡처도 권리 확인 완료를 뜻하지 않는다. .env·키·캐시 DB·운영 포획 DB는 제외했다.
