# NF2001~NF2007 검증 결과

기준일은 2026-10-23입니다. 기존 판정을 유지하며 이번 편집에서 API 호출·테스트·설정 변경을 수행하지 않았습니다. 심화 F2013~F2016은 미선택입니다.

선행 보완은 연락처 검사·캐시/재시도, `.env.example` 안내, README/출처 문서, 자산/위키 기록과 NF 회귀 8개입니다. 이번에는 문서만 편집했습니다.

## 판정과 검증 범위

| 번호 | 판정 | 실행 근거 및 남은 확인 |
|---|---|---|
| NF2001 | 확인 필요(단일 사용자 측정 양호) | 실제 LLM 2.016~6.031초(2026-10-23 선행 실행); 최신 로컬 약점 중앙값 0.141초·기술 0.328초. 측정 표본상 성능 리팩터링 불필요. 허용 응답시간·동시 사용자 수·p95 목표는 미정. |
| NF2002 | 통과 | 기존 수집 검색어 재실행 시 HTTP·임베딩 호출 없음; 문서 재색인 changed_chunks=0 회귀 테스트 통과. 연락처 없는 캐시 조회도 유지. |
| NF2003 | 통과(현 소스 범위) | 환경변수 키 관리·.env ignore 유지. 소스/문서/데이터/설정 텍스트 95개에서 실제 설정된 키 정확 일치 및 sk- 패턴 0건. 최종 ZIP은 미제공. |
| NF2004 | 통과 | 의도적인 PRIVATE_API_KEY/PRIVATE_FULL_PROMPT/PRIVATE_TRACE 예외를 UI에 전달해 사용자 화면에 표시되지 않음을 AppTest로 확인. traceback은 화면에 노출하지 않음. |
| NF2005 | 통과 | 수집 DocumentService, 색인 VectorStore, 검색/생성 RagService 및 LangGraph, 도메인 Catalog/battle/natural_search, UI 모듈 분리와 전체 회귀 실행 유지. |
| NF2006 | 확인 필요(코드 보완 완료) | 환경변수 연락처를 User-Agent에 반영. 미설정/비ASCII/제어문자는 새 요청 전에 차단하며 캐시 허용. 간격·429/503·Retry-After·3회 재시도 검증. 현재 운영 연락처는 공란이며 실제 전송 성공 미실행. |
| NF2007 | 확인 필요(출처 기록 보완 완료) | 공식 정책/라이선스 조사, PokéAPI/CSV/기술/Wikipedia/이미지 출처 문서화. 15개 위키 문서별 출처·조건, 15개 자산의 파일 해시와 권리 미확인 상태 기록. 이미지 원작자·허락 증빙과 원작 콘텐츠 권리는 사용자 확인 필요. |

NF2001·NF2006·NF2007은 확인 필요 상태입니다. 공식 셀프 24번의 통과는 출처·조건 **기록** 여부의 판정이며, NF2007의 실제 권리·배포 조건 확인을 대신하지 않습니다.

## 미확인 사항과 확인 절차

### NF2001 성능

사용자 또는 상호 점검자가 대표 질문 대기시간의 사용 지장 여부를 확인해야 합니다. 기존 측정만으로 사용성 통과를 선언하지 않습니다. 운영 SLA·동시성·p95는 추가 검증이며 미측정입니다.

[추가 증빙 필요: 실제 사용자의 대표 질문 대기시간과 사용성 확인 의견입니다. 기존 응답시간을 재사용하고 새로운 유료 호출은 수행하지 않았습니다.]

### NF2006 외부 호출

운영자가 실제 소유·관리하는 영문 연락처를 `WIKI_CONTACT`에 설정하고, 별도 허용 작업에서 단일 읽기 요청의 User-Agent 적용·응답 상태를 확인해야 합니다. 현재 연락처는 공란이며 실제 신규 송신은 미실행입니다. 빈 값/비ASCII/제어문자 차단, 기본 6.2초 간격·3회 시도·429/503·Retry-After 검증은 기존 모의 시험을 재사용합니다. 캐시는 연락처 없이도 유지합니다.

[추가 증빙 필요: 운영 연락처가 적용된 실제 Wikipedia 요청의 시각·식별자 적용·정상 응답 기록입니다. 실제 오류를 유발하거나 재색인할 필요는 없습니다.]

### NF2007 출처·권리

[출처 문서](SOURCES_AND_LICENSES.md), [위키 15개 기록](wikipedia_sources.json), [자산 15개 기록](asset_provenance.json)을 동봉합니다. 사용자 제공 배경 9개·몬스터볼·오박사·로토무 2개·루트 이미지 2개의 원출처와 허락, 원작 콘텐츠 배포 권한은 미확인입니다.

[추가 증빙 필요: 원게시 페이지·적용 라이선스 또는 실제 권리자의 이용 허락 기록입니다.]

최종 제출 폴더는 운영자가 키·개인정보·캐시 제외와 라이선스 고지를 다시 확인해야 합니다. 셀프 집계는 통과 18·실패 0·미확인 3·해당없음 6이며 [공식 XLSX](evidence/checklists/Pokefield_셀프점검결과_20261023.xlsx)를 변경하지 않았습니다.
