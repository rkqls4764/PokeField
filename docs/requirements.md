# PokéField 요구사항 정의 및 충족 현황

> 제출 문서 보완 기준: 2026-10-23의 기존 실행 기록과 공식 셀프 점검 결과입니다. 이번 문서 보완에서는 테스트·유료 API·재색인을 실행하지 않았습니다. 실제 GMS, 로컬 Python, 응답 캐시, 저장 응답 재생, FakeLLM/FakeEmbeddings를 구분합니다. 심화 F2013~F2016은 **미선택**입니다.

기준일: 2026-10-23. 근거는 사용자 제공 「AI코어프로젝트_2회차_요구사항정의서」, 현재 코드와 실제 검증 결과입니다. 원본 PDF는 변경하지 않고 본 프로젝트의 구현/검증 대조표를 최신화합니다.

## 목적·범위·판정 원칙

### 도메인 선정과 데이터 조건

포켓몬은 타입·특성·능력치·진화·세대 차이를 구조화 데이터로 검증할 수 있고, 설정·변화 이유처럼 외부 문서 근거가 필요한 질문도 함께 다룰 수 있어 선정했습니다. 확보한 규모는 **1,025종·1,351형태·6,260세대별 행**입니다. 종 수와 형태 수, 색인 청크 수는 서로 다른 지표입니다. 메타 색인은 6,260건이며 외부 문서는 한국어 Wikipedia 10종 범위의 15개 문서-종 연결, 64청크입니다.

근거가 필요한 대표 질문은 다음과 같습니다.

1. “팬텀의 6세대와 7세대 특성은 어떻게 달라졌나요?”는 두 세대 메타데이터가 필요합니다. 변경 이유는 외부 문서에 있을 때만 설명합니다.
2. “피카츄는 무엇으로, 어떤 조건에서 진화하나요?”는 진화 관계와 조건 근거가 필요합니다.
3. “9세대에서 몸통박치기를 레벨업으로 배우는 포켓몬은?”은 버전·습득 방법이 있는 기술 데이터가 필요합니다.
4. “리자몽에게 바위 공격은 몇 배인가요?”는 실제 복합 타입과 세대별 상성 규칙이 필요합니다.

PokéAPI는 구조화 메타데이터·기술 데이터, Wikipedia는 외부 설명의 원천입니다. 세부 조건과 미확인 이미지 권리는 [출처 및 이용 조건](SOURCES_AND_LICENSES.md)을 따릅니다. API 접근 가능성을 캐릭터 콘텐츠 재배포 허락으로 해석하지 않습니다.

포켓몬 구조화 데이터와 Wikipedia 문서를 검색해 근거를 갖춘 질문 응답을 제공합니다. 필드·도감·수집·추천 추적은 동일 데이터/RAG를 활용하는 응용 UI다. `pokemon_id`(형태)와 `species_id`(종), 세대의 역학 정보와 게임별 실제 등장 여부를 구분합니다. 없는 값/조건/이유는 만들어내지 않습니다.

통과는 기재된 실행 범위에서의 판정이며 코드 존재만을 뜻하지 않습니다. 캐시 재생·모의 테스트·실제 유료 API를 구분합니다. 필수 기능은 12/12 재검증 통과이나, 서비스 출력 품질 문제와 비기능 미확인 사항은 별도로 남깁니다.

## 심화 기능 실제 수준

**제출 심화 과제는 미선택입니다.** 아래 표는 코드의 참고 수준이며 선택 과제 통과 판정이나 결과 비교가 아닙니다.

|---|---|---|---|
| F2013 | 직접 프론트 구현·서버 분리 | 부분 구현 | 맵·도감은 HTML/CSS/JS Component v2. 질문/답변/근거는 Streamlit 채팅/expander이며 별도 API 서버 기반 전체 프론트 요건 미충족 |

## 해결한 문제와 남은 제한

1. 선택형 특수 질문에서 필수 색인 메타데이터가 빠지던 조기 반환을 보완했습니다. 구조화 근거를 앞에 유지해 기존 인용 번호를 보존했습니다.
2. 결과 카드 선택 시 기본 탭 값만 바꾸던 동작을 상태 추적 탭으로 전환했습니다. 기술 검색 결과에도 선택 버튼을 추가했습니다.
3. 키 누락·색인 누락·연결 오류를 구분하고 키 없는 로컬 질문을 유지했습니다.
4. Wikipedia 연락처가 없어도 요청하던 경로를 새 요청 전에 차단했습니다. 실제 연락처/권리를 임의 생성하지 않았습니다.
5. 남은 서비스 품질: 팬텀 비교가 유효한 변경 설명 뒤에 “지금 가진 근거만으로는 확인하기 어렵구나”를 덧붙입니다. `generate()`의 부분 근거 부족 처리 개선이 필요하며 문서 작업 중 코드는 수정하지 않았습니다.

최신 수치·실행 구분은 [검증 요약](VERIFICATION_SUMMARY.md), 상세 출처는 [출처/이용 조건](SOURCES_AND_LICENSES.md)을 따릅니다. 원본 데이터/운영 색인/설정 변경 없이 문서만 최신화했습니다.
