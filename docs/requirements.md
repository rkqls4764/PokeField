# 요구사항 대조 및 후속 구현

근거: 배포된 AI 코어 프로젝트 2회차 요구사항정의서, 교육생 배포 Streamlit 실습과 영화 도메인 데이터 구조.

| 요구사항 | 기초 작업 상태 | 남은 작업 |
|---|---|---|
| F2001 데이터 로드/색인 텍스트 | 실제 데이터 로드·텍스트 변환 함수 구현 | 내용별 검색 품질 점검 |
| F2002 메타데이터 색인 | 고정 ID·스칼라 메타데이터 준비 | Chroma 임베딩/upsert/건수·중복 검증 |
| F2003 검색어 추출 | 프롬프트 초안 준비 | 모델 호출·JSON 파싱·자체 항목 포함 검증 |
| F2004 외부 문서 수집/선별 | 연결 계획 작성 | 위키 API·캐시·선별·자체 문서 강제 포함 |
| F2005 청킹/별도 색인 | 설정과 ID 설계 준비 | splitter·문서 upsert |
| F2006 검색/근거 병합 | 메타데이터 문서 구조 준비 | 항목 필터 의미 검색·선택 메타 필수 포함·중복 제거 |
| F2007 LangGraph | retrieve→generate 그래프 조립 함수 | 실제 노드 구현·실행 검증 |
| F2008 근거 표시 | 인용 번호 추출 함수·UI 준비 | 실제 답변 연결 후 표시 대조 |
| F2009 항목 선택/대화 분리 | 선택 UI·항목+세대 상태 구조 구현 | 실제 대화 생성과 전환 검증 |
| F2010 도메인 특화 | 데이터 기반 세대 비교 화면 구현 | 외부 검색 근거와 연계 |
| F2011 자연어 조건 탐색 | 선택형 필터만 구현 | 자연어 조건 해석·후보 검증·결과에서 대화 이동 |
| F2012 상태/오류 안내 | 데이터·키·연결 안내 구현 | 실제 수집/생성 단계 진행률 |
| NF2001~NF2007 | 모듈/환경변수/출처/로컬 캐시 계획 | 응답속도·캐시·외부 호출 정책·이용 조건 검증 |

전체 RAG 필수 기능 완료로 간주하지 않습니다. F2013~F2016 심화 기능은 아직 선택/구현하지 않았습니다.
