# PokéField 요구사항 정의 및 충족 현황

기준일: 2026-10-23. 근거는 사용자 제공 「AI코어프로젝트_2회차_요구사항정의서」, 현재 코드와 실제 검증 결과다. 원본 PDF는 변경하지 않고 본 프로젝트의 구현/검증 대조표를 최신화한다.

## 목적·범위·판정 원칙

포켓몬 구조화 데이터와 Wikipedia 문서를 검색해 근거를 갖춘 질문 응답을 제공한다. 필드·도감·수집·추천 추적은 동일 데이터/RAG를 활용하는 응용 UI다. `pokemon_id`(형태)와 `species_id`(종), 세대의 역학 정보와 게임별 실제 등장 여부를 구분한다. 없는 값/조건/이유는 만들어내지 않는다.

통과는 기재된 실행 범위에서의 판정이며 코드 존재만을 뜻하지 않는다. 캐시 재생·모의 테스트·실제 유료 API를 구분한다. 필수 기능은 12/12 재검증 통과이나, 서비스 출력 품질 문제와 비기능 미확인 사항은 별도로 남긴다.

## 해결한 문제와 남은 제한

1. 선택형 특수 질문에서 필수 색인 메타데이터가 빠지던 조기 반환을 보완했다. 구조화 근거를 앞에 유지해 기존 인용 번호를 보존했다.
2. 결과 카드 선택 시 기본 탭 값만 바꾸던 동작을 상태 추적 탭으로 전환했다. 기술 검색 결과에도 선택 버튼을 추가했다.
3. 키 누락·색인 누락·연결 오류를 구분하고 키 없는 로컬 질문을 유지했다.
4. Wikipedia 연락처가 없어도 요청하던 경로를 새 요청 전에 차단했다. 실제 연락처/권리를 임의 생성하지 않았다.
5. 남은 서비스 품질: 팬텀 비교가 유효한 변경 설명 뒤에 “지금 가진 근거만으로는 확인하기 어렵구나”를 덧붙인다. `generate()`의 부분 근거 부족 처리 개선이 필요하며 문서 작업 중 코드는 수정하지 않았다.

최신 수치·실행 구분은 [검증 요약](VERIFICATION_SUMMARY.md), 상세 출처는 [출처/이용 조건](SOURCES_AND_LICENSES.md)을 따른다. 원본 데이터/운영 색인/설정 변경 없이 문서만 최신화했다.
